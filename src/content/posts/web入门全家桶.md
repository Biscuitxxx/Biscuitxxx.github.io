架构：Vue3 + SpringBoot + 数据库（MySQL / PostgreSQL） + MinIO 对象存储

MinIO 对象存储是我最近在折腾的组件，专门用来存放视频这类大体积文件。
有趣的点：可以单独部署一台独立的对象存储服务器，只负责文件存储，生成访问链接提供给前后端使用。
如果这台存储服务器和 Web 服务器放在同一局域网，**不需要外网，仅内网互通即可通信**。

普通玩家最常用的是单体部署方案：整套架构全部部署在同一台服务器上，上手简单。
而分开多机部署的方式，虽然搭建稍复杂，但后续项目迁移、横向扩容会更加灵活方便。
数据库可使用 DBeaver 可视化客户端工具进行管理。
